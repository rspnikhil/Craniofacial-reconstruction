# Craniofacial-Reconstruction using Generative Models (GANs)

 There are three GANs we are using here for craniofacial reconstruction.
 1. CycleGAN
 2. Pix2Pix
 3. CUT

# Prerequisites

    Linux or macOS
    Python 3
    CPU or NVIDIA GPU + CUDA CuDNN

# Getting Started
# Installation

    Clone this repo:

git clone [https://github.com/junyanz/pytorch-CycleGAN-and-pix2pix](https://github.com/rspnikhil/Craniofacial-reconstruction.git)

    Install PyTorch and other dependencies. For Conda users, you can create a new Conda environment by

conda env create -f environment.yml

and then activate the environment by

conda activate pytorch-img2img
